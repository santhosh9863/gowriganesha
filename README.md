Sankalpa — Festival Management Platform

A modern festival management platform built for Sri Gowri Ganesha Geleyara Balaga, designed to simplify volunteer coordination, sponsor collections, daily transactions, expenses, and festival operations.

✨ Features

- 📊 Dashboard — Real-time overview of collections, expenses, balance, and festival progress
- 🤝 Sponsor Management — Track sponsors, commitments, collections, and pending amounts
- 💰 Daily Collections — Quickly record and manage daily collection entries
- 🧾 Expense Management — Track and organize festival expenses
- 📱 Festival QR — Display and share the official payment QR
- 👥 Volunteer Management — Monitor registered volunteers and activity
- 🔔 Notifications — Keep volunteers and administrators informed
- 🔐 Role-Based Access — Separate administrator and volunteer capabilities
- ☁️ Firebase Backend — Real-time cloud data synchronization
- 📱 Responsive Interface — Designed for mobile, tablet, and web

🛠️ Tech Stack

- Flutter
- Dart
- Firebase
  - Cloud Firestore
  - Firebase Authentication
  - Firebase Cloud Messaging
  - Firebase Hosting
- Riverpod
- GoRouter

🏗️ Architecture

The application follows a structured architecture with separated presentation, state management, services, models, and Firebase data layers to keep the project maintainable and scalable.

🎯 Purpose

Sankalpa replaces manual festival management workflows with a centralized digital platform, providing organizers and volunteers with a reliable way to manage collections, expenses, sponsors, and day-to-day festival activities.

📌 Project Status

Production application — actively used for festival management.
